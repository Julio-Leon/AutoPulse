# AutoPulse — Traffic & Accident Analytics

A data engineering project combining historical vehicle collision data
with near-real-time traffic events.

## Technology stack

- Python
- Apache Kafka (KRaft)
- Apache Spark / PySpark
- Apache Airflow
- Parquet
- PostgreSQL
- AWS S3 and related AWS services

## Development environment

Windows filesystem, VS Code, WSL Ubuntu, and Docker Compose.
